# 示例工作流

所有示例默认使用 `mock` 离线连接，不会调用付费模型。
在本次测试机上可直接运行；其他机器需先运行 `tools/mock_gateway.py` 并配置同名连接。
真实使用时，在节点里选择自己的连接和可用模型。

`api/` 中 01–13 为 ComfyUI API 格式工作流，可导入 ComfyUI，或以 `{"prompt": 工作流}` 发送到 `/prompt`。

- 01–02：对话和 SSE
- 03–05：图片生成、直接传图编辑、异步图片
- 06–07：视频和首尾帧参考
- 08：语音合成连接转录与保存
- 09–10：Suno 与 Midjourney
- 11：原生 Messages 请求
- 12：提交任务与等待分开
- 13：JSON 数据工具

`14-realtime-and-image.json` 是可直接拖入的图形工作流。先在实时节点选择连接和实时模型，
点击开始语音或文字连接，对话后点击结束并应用，再运行工作流。
快照 ID 已清空，避免引用本机以外不存在的录音。浏览器需要受信 HTTPS 或 localhost。
