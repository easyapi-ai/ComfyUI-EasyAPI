# ComfyUI-EasyAPI

简体中文 · [English](README.en.md)

在 ComfyUI 中使用 EasyAPI 对话、图片、视频、音频及实时语音。模型列表按当前连接的权限和所选操作筛选，常用参数直接填写，模型专属参数按需显示。

## 安装

要求 Python 3.11+ 和 ComfyUI V3 节点接口；验证基线为 ComfyUI 0.41.2 / 前端 1.55.17。

1. 将 `ComfyUI-EasyAPI` 放到 `ComfyUI/custom_nodes/`。
2. 使用 **ComfyUI 实际运行的 Python** 安装依赖：

   ```shell
   python -m pip install -r custom_nodes/ComfyUI-EasyAPI/requirements.txt
   ```

3. 重启 ComfyUI，刷新浏览器，在 `EasyAPI` 分类中添加节点。

不需要本地大模型。依赖复用 ComfyUI 的 PyTorch、Pillow、NumPy；前端扩展已随包提供，无需 Node.js 编译。

## 连接与模型

从左侧 **EasyAPI** 或顶部扩展菜单打开连接管理。只有一个连接时，节点会直接使用它；有多个连接时，新节点会使用设定的默认连接，也可以通过节点右键菜单指定连接。新连接默认使用官方网关 `https://token.easyapi.com`。

- **手动 API Key**。适合已有密钥或自定义网关，可在 ComfyUI 的同源 HTTP 或 HTTPS 页面保存。已保存的密钥只显示尾号，编辑时留空会保留原值。
- **官网授权**。展开连接表单下方的「官网授权」后跳转到 EasyAPI 官网。ComfyUI 后端为当前实例领取 30 天的专用令牌。重新授权可继续使用，吊销在 EasyAPI 控制台完成。官网授权需要可信 HTTPS 或 localhost。
- **部署密钥**。在 ComfyUI 服务进程设置 `EASYAPI_API_KEY_FILE` 指向挂载的 Secret 文件，或设置 `EASYAPI_API_KEY`。可通过 `EASYAPI_BASE_URL` 指定网关。侧栏显示只读连接 `easyapi-env`。

「测试连接」只读取权限模型列表。工作流只保存连接别名。官网授权的专用令牌仅由 ComfyUI 后端保存和使用。

打开连接管理后，已保存的连接卡片会自动查询额度，也可点击卡片上的刷新图标。卡片显示可用的钱包余额、API 密钥总额、已用和剩余额度，以及已配置的周期预算。旧网关通过 `/usage/token` 返回密钥额度。

### 创作预设

可按连接、操作和模型保存命名预设。设为操作默认的预设会给新节点填入它的模型和参数；打开已有工作流时使用工作流保存的模型和数值。也可在节点中主动应用预设，或把刚调好的模型参数保存为预设。

按操作选择兼容模型。实时对话、TTS、转录等能力分开筛选。模型列表按连接、操作和语言缓存，浏览器最多复用 2 分钟，服务端权限列表有效期为 5 分钟。可以右键节点选择「刷新 EasyAPI 模型列表」。模型列表为空时，可在侧栏检查连接状态和 Key 权限。

工作流只保存连接别名，Key 存在 ComfyUI 后端的持久用户目录。可访问同一 ComfyUI 实例的用户属于同一可信工作区，能够使用已配置连接；对外开放应由部署层提供访问控制。

## 当前节点

| 节点 | 用途 |
|---|---|
| EasyAPI 对话 | Chat、Responses、Claude Messages、Gemini 和文本补全 |
| EasyAPI 图片 | 根据参考图片自动选择同步文生图或图生图，仅输出 image、url、响应 |
| EasyAPI 视频 | 使用统一 `/v1/videos` 接口生成视频，输出视频、URL、响应 |
| EasyAPI 视频提示词调优 | 独立选择文本模型、目标视频模型和素材，输出优化提示词、分析及结构化结果 |
| EasyAPI 语音合成 | 文本转原生 AUDIO |
| EasyAPI 转录与翻译 | 使用兼容模型处理 AUDIO 或带音轨的 VIDEO |
| EasyAPI Token 计数 | 对兼容消息请求计数 |
| EasyAPI 素材与参考组 | 组合额外素材、已有 URL 与参考角色 |
| EasyAPI JSON 工具 | 解析、读取、合并、设置、追加及格式化 JSON |
| EasyAPI 查询任务 / 等待任务 | 查询或恢复已有任务，不重新提交生成 |
| EasyAPI 下载结果 | 下载并解码已有结果 |
| EasyAPI 实时对话 | 浏览器麦克风或文字会话，冻结后供工作流读取 |
| EasyAPI 预览 | 预览文本、JSON、图片、音频、视频及素材组 |

共 14 个注册节点。旧工作流如果使用了 `EasyAPITools`、Moderation、Search、Rerank、Embedding、NativeRequest、Midjourney 或 Suno，需要替换或删除相应节点。高级参数只接受当前操作的参数 JSON。

## 表单与语言

基础表单提供提示词和常用设置，动态表单只显示当前模型已声明的参数。高级 JSON 默认折叠，保留 `0`、`false`、数组和对象；表单与 JSON 编辑同一份参数，不需要填写同一字段两次。切换连接、模型或操作后，以当前组合的能力和参数为准。

图片节点按当前 Key 的模型权限读取文生图或图生图参数，模型广场的隐藏设置不影响参数读取。尺寸、数量、质量等已声明设置直接显示，其余选项放在“更多参数”。模型允许自定义尺寸时，可选择预设或填写宽高，并按模型的范围、倍数、像素面积和比例限制校验；未声明可设置参数时会显示提示，仍可使用高级 JSON。

模型旁显示当前参数的预计费用。点击价格或信息图标可查看单价、折扣和估算来源。v1 以美元显示，v2 表达式以人民币显示。旧网关可显示有依据的目录参考价，最终费用以实际结算为准。

节点名称、输入输出及控件跟随 ComfyUI 的语言设置，提供 English（`en`）、简体中文（`zh`）和繁體中文（`zh-TW`）节点定义。模型 ID、协议值、参考角色和 JSON 键保持原值，不因翻译改变。

### 提示词编辑与视频调优

可在画布中添加 **EasyAPI 视频提示词调优** 节点，将其“优化提示词”输出连接到视频节点的提示词输入。调优用的连接、文本与素材分析模型，与目标视频的连接、模型和参数分别选择；也可选中一个 EasyAPI 视频节点，复制它未通过连线提供的目标设置。

“单独调优”只运行这个调优节点和它所需的上游，不运行下游视频生成；上游若包含图片、音频或视频生成节点，也可能运行并计费。原始提示词和素材可以来自连线，执行时使用上游实际结果，不以控件默认值替代。优化输出不会写回原始提示词，分析和完整结构化结果分别从另外两个输出取得。

同一节点使用隐藏的稳定标识隔离缓存，复制节点会分配新标识。工作流正常执行时，服务端按实际输入判断能否复用调优结果；点击“重新调优”会更新版本并请求新的调优。浏览器恢复的结果仅供查看或复制，不替代服务端执行校验。需要完整界面时可点击“展开详情”，其中仍通过节点局部运行解析上游连线。

提示词框右下角的工具栏提供撤销、重做、历史、标签、翻译和通用优化。选择视频模型后，可打开调优面板，按通用、剧集或电商场景，以及文生、首帧、首尾帧、参考素材或视频编辑形态进行快速优化、完整分析和失败片段诊断。Wan 3 保留专用写作规则，其他视频模型使用通用规则及其实际能力元数据。

调优读取当前模型参数与已就绪素材，并支持按时间区间分析成片。尚未生成的上游素材会显示待就绪状态。文本与素材分析模型均从所选连接的可用模型中选择，调用按该模型正常计费。结果先预览，再应用到提示词；参数建议单独展示。原文、素材或生成上下文变化后，旧结果仍可查看和复制，应用前需重新校验。

素材分析和结构化调优均使用非流式请求，界面按准备、分析、调优和校验阶段显示等待时间；完整结果通过校验后一次性展示，不输出半截 JSON。每个模型阶段默认等待最多 300 秒，超时会说明具体阶段。收起面板不会取消任务；刷新后可恢复草稿和任务查看，连接中断时可恢复原任务而不重新提交。

## 视频与素材

视频节点统一使用 `/v1/videos`。可直接连接：

- `first_frame`、`last_frame`：首帧与尾帧 IMAGE；
- `reference_image_1/2`：参考图片；
- `reference_video_1/2`：参考视频；
- `reference_audio_1/2`：参考音频；
- `references`：由素材节点组合的额外参考组。

输入模式默认 `auto`，根据已连接素材和模型声明选择。端口可用性、素材数量及组合限制以当前模型为准；尾帧、首尾帧和多模态参考并非每个模型都支持。

输出依次为视频（原生 VIDEO，可直接连接 SaveVideo）、对应视频的上游 URL 和完整响应。URL 不包含封面或输入素材地址；仅返回二进制或内联视频时为空。旧图形工作流自动迁移视频和 JSON 连线，已移除输出的连线会断开并提示；API 格式工作流需使用新索引 `0/1/2`。

支持文件或内联的接口直接使用本地素材；需要公网 URL 的接口通过配套 `/v1/media` 转存。旧网关没有素材接口时，URL-only 能力需使用已有公网链接。单素材默认上限 100 MiB，大文件通过文件流传输。具体边界见 [接口覆盖清单](docs/INTERFACE-COVERAGE.md)。

## 任务与实时会话

生成节点每次明确排队都会发起新请求。图片节点仅调用同步接口：无参考图时文生图，连接图片、图片参考组或在参数中填写图片 URL 后自动切换图生图。输出为 image、首个上游 url 和完整响应；没有上游 URL 时 url 为空。

视频节点可关闭“等待结果”，此时视频为空、URL 为空，响应保留提交结果；在查询或等待节点的任务历史中选择，或填写任务 ID 恢复。其他异步节点仍可直接连接任务输出。任务 ID 和轮询信息保存在持久用户目录；停止等待、超时或重启后可以恢复。停止本地等待不等于取消上游任务，提交超时且未收到 ID 时应先核对平台任务，避免重复提交。

实时对话使用节点上的连接、语音/文字、静音、打断及结束控件。冻结或应用对话后，再执行工作流读取文本和 AUDIO 快照。活跃会话独立于生成队列，导入工作流不会自动开启麦克风。

麦克风需要受信任 HTTPS 或 localhost，普通内网 HTTP 页面不能采音。Key 仅由后端加入上游连接；结束会话、关闭页面或移除节点会释放资源。

## 示例与验证

[示例工作流](examples/README.md) 包含图片编辑、视频首尾帧、语音转录、Claude Messages、视频参考音频及分离任务流程。示例默认引用 `mock` 连接，运行前先启动离线服务并配置同名连接：

```shell
python tools/mock_gateway.py --port 3199
```

本机模拟地址为 `http://127.0.0.1:3199`，公开测试 Key 为 `mock-only-key`；Docker 内使用模拟服务的容器网络地址。模拟服务不向外部网络发请求，生成的 PNG、WAV、MP4 只验证协议和媒体链路，不代表模型创作效果。

```shell
python -m pip install -e '.[test]'
python -m pytest tests -q
```

环境安装与回滚见 [部署说明](docs/DEPLOYMENT.md)，既有验证及其边界见 [验收记录](docs/VERIFICATION.md)。本轮不进行付费上游生成、上传或实时调用。
